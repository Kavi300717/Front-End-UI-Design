# NovaSpark

NovaSpark is a responsive SaaS landing page for an AI-powered workspace. It presents the product, features, customer testimonials, pricing plans, company metrics, and footer links.

## Included Sections

- Navigation and hero area
- Product feature cards
- Team statistics
- Customer testimonials
- Pricing plans
- Company footer with product, contact, and legal links

## Tech Stack

- HTML5
- CSS3
- Remix Icon

## Run Locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.
